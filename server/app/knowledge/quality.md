# 품질관리

품질관리에서 정상, 확인 필요, 우선검사 등급과 최근 제품을 확인합니다. 제품을 선택하면 규칙 기반 등급과 판정 근거, 공정 기록, 보조 분석을 볼 수 있습니다.

제품 상세의 보조 분석은 기존 ML/DL 모델의 저장 결과를 표시합니다. RPF 완료 후 분석이 자동 실행됩니다. 코파일럿은 재분석을 요청하거나 등급과 점수를 수정하지 않습니다.

제품 상세에서 단계별 소요시간, 기록에 따른 권장 점검 순서, 복사 가능한 품질보고서 초안을 확인합니다. 코파일럿에 RPF-014 점검 순서 알려줘 또는 RPF-014 품질보고서 초안 작성해줘라고 질문할 수도 있습니다. 점검 안내는 원인 확정이나 실제 검사 판정이 아닙니다.
