# 데이터 조회

데이터 조회 메뉴에서 시작일·종료일, 제품군, 등급, 제품 ID를 설정한 뒤 조회를 누릅니다. 제품 ID는 일부 문자열로도 검색할 수 있습니다. 초기화를 누르면 필터를 지웁니다.

CSV 다운로드는 데이터 조회에서 필터를 적용한 뒤 누릅니다. 화면의 현재 페이지만이 아니라 조회 조건에 맞는 전체 제품을 내려받습니다. 필터를 바꿨다면 먼저 조회를 눌러야 다운로드할 수 있습니다.

제품 행을 선택하면 RPF 상세를 확인할 수 있습니다. 저장된 분석 결과가 없으면 점수는 비어 있으며, CSV에서도 해당 셀은 빈칸입니다.
