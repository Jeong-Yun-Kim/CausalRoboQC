# 용어

RPF는 제품별 작업 순서, 작업시간, 재시도, 오류 등 공정 이력을 하나로 묶은 기록입니다.

정상, 확인 필요, 우선검사는 공정 이력의 규칙 기반 분류이며 실제 검사 PASS/FAIL을 뜻하지 않습니다. 확인 필요는 일부 공정 이상이 있어 추가 확인이 필요한 제품이고, 우선검사는 오류나 반복 실패 등으로 먼저 검사할 필요가 있는 제품입니다.

공정 이상도는 작업시간, 재시도, 오류 등의 특징이 정상 공정과 얼마나 다른지 나타냅니다. 불량 확률은 아닙니다.

검사 위험도는 공정 이력이 품질검사 FAIL 패턴과 얼마나 유사한지 나타내는 보조 점수입니다. 현재는 합성 데이터 기반 시험 지표입니다. 저장된 점수만으로 개별 특징의 기여도나 인과 원인을 확인할 수 없습니다.

공정 단계 시간 이상도는 HOME부터 RELEASE까지 각 작업 단계의 시간 패턴이 정상 공정과 얼마나 다른지 나타냅니다. 단계 시간이 부족하면 결과가 없을 수 있습니다.

코파일럿은 제품 설명, 제품·제품군 비교, 기간 요약, 등급 분포, 공정 추세, 앱 사용법을 지원합니다. 제품 질문에는 제품 ID를, 기간 질문에는 최근 7일 또는 YYYY-MM-DD 시작일과 종료일을 넣어주세요.
