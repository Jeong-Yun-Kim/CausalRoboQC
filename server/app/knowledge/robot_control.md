# 로봇 제어

로봇 제어에서 연결 상태와 자세 준비 상태를 확인하고 1회 실행을 누릅니다. 완료된 작업의 실제 결과를 정상 또는 이상으로 선택해 확정합니다. 이상이면 해당 원인을 선택합니다.

반복 실행은 화면에 안내되는 준비 데이터 수만큼 완료된 1회 실행 결과를 확정하면 사용할 수 있습니다. 준비가 끝나면 반복 실행을 누릅니다. 코파일럿은 실행 버튼을 대신 누르거나 로봇을 제어하지 않습니다.

준비 데이터를 초기화하면 반복 실행이 다시 잠깁니다. 원본 작업과 RPF 이벤트 이력은 유지되며, 필요한 1회 실행 결과를 다시 확정해야 합니다.
